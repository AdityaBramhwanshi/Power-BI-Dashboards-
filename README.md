Project Description

This project presents an interactive business intelligence dashboard analyzing retail sales performance using Power BI.
The dashboard transforms transactional data into actionable insights for decision-making.

Dataset : 

Sample Superstore dataset sourced from Kaggle.

-The dataset contains:
-Orders and shipping information
-Product categories and sub-categories
-Regional sales distribution
-Customer segments
-Sales, profit, and discount metrics

Tools Used :

-Power BI (Data Modeling & Visualization)
-DAX (Calculated Measures & Columns)
-Data Cleaning using Google Sheets

Key Features of Dashboard :

-KPI cards showing total sales, profit, orders, and margin
-Monthly sales trend visualization
-Regional performance comparison
-Category and sub-category profitability analysis
-Customer segmentation insights
-Interactive slicers for dynamic filtering

Business Insights Generated : 

-Identified top performing regions and categories
-Highlighted profit leakage due to discounts
-Showed customer segment revenue contribution
-Revealed seasonal sales patterns

Business Value : 

This dashboard demonstrates how data visualization tools can help organizations:
-Monitor performance metrics
-Identify growth opportunities
-Optimize pricing strategies
-Support data-driven decision making

Learning Outcomes : 

-Through this project I learned:
-Data modeling in Power BI
-Writing DAX measures and calculated columns

-Designing executive-level dashboards
-Translating data into business insights
